## 🚀 Quick Start

### Prerequisites
- A GitHub account
- Git installed on your computer

### Setup Instructions

1. **Clone or Initialize the Repository**
   ```bash
   cd .github.io
   git init
   ```

2. **Add Files**
   All HTML, CSS, and this README are included in the repository.

3. **Push to GitHub**
   ```bash
   git add .
   git commit -m "Add complete portfolio website"
   git push -u origin main
   ```

4. **View Your Site**
   - Visit: `https://MrsJohnsonEdTech.github.io`
   - Note: It may take a few minutes for the site to appear

## 🎨 Customization

### Colors
The portfolio uses a professional color scheme:
- **Primary Blue**: `#003366`
- **Secondary Blue**: `#0052A3`
- **Accent Gold**: `#FFB800`
- **Light Background**: `#F9F9F9`

To change colors, edit the color values in `styles.css`.

### Content
Update content directly in each HTML file:
- Replace placeholder text with your information
- Update social media links
- Add actual project GitHub links
- Modify dates and experiences

### Images
To add images:
1. Place image files in the repository
2. Reference them in HTML: `<img src="image-filename.jpg" alt="Description">`

### Projects
To add or modify projects:
1. Edit `projects.html`
2. Copy a project card structure
3. Update project details, technologies, and descriptions
