Jack's Projects

10th Grade - AP Computer Science Principles

Chess

A homemade chess game built with CMU CS Academy. While it doesn't have all the functionality needed to function as a complete chess game, all the pieces are able to move.

Description

This was the project submitted for the CPT (Create Performance Task) this year. It demonstrates foundational game development and piece movement logic.

Key Challenges

  • Figuring out how to move pieces turned out to be more of a challenge than expected
  • Implementing logic to stop pieces from moving onto occupied spaces

Lessons Learned

  • There is often more than one way to solve a problem; if one way doesn't work, you can always try again
  • Coding takes a lot of patience, as much of the process is just trial and error

Cookie Clicker Clone

An attempt to recreate as much of Cookie Clicker as possible with the time available. Focuses on early game functionality and clicking mechanics.

Description

This project successfully implements clicking mechanics and progression systems, demonstrating game loop and state management concepts.

Key Challenges

  • Making the CPS (cookies per second) constant work correctly
  • Creating better graphics within the library constraints

Lessons Learned

  • The solution you want isn't always the solution you have to settle for
  • Deepened understanding of the onStep() function and how to use it effectively

Unfair Tetris

An attempted recreation of Tetris that is intentionally buggy. The project embraces its imperfections, earning the name "Unfair Tetris."

Description

This project demonstrates grid-based game mechanics and collision systems, despite intentional bugs that make the gameplay unpredictable.

Key Challenges

  • Clearing a row without clearing the entire piece was difficult to implement correctly
  • Rotating pieces without misaligning them proved challenging; solved with a realignment procedure

Lessons Learned

  • Work doesn't always have to be perfect; sometimes "good enough" is good enough
  • Taking more creative approaches can turn bugs into features

Pong

A take on the classic Pong game with intentional quirks that make gameplay more interesting than the original.

Description

This project implements ball physics and paddle mechanics, demonstrating collision detection and game state management.

Key Challenges

  • Collisions between the ball, paddles, and walls were not straightforward to figure out
  • Making the paddles work as intended proved difficult

Lessons Learned

  • This project deepened understanding of the code language
  • Learned how to better code collisions and physics mechanics
