How to Add Your Projects

To add a new project to your portfolio, duplicate the project-card div template and customize it with your project details.

Template Instructions:

  1. Copy the project-card div: Find the HTML comment "" and copy the structure below it.
  2. Update the project title: Change the h2 text to your project name.
  3. Update the status badge: Change the span class "project-status" text to "Completed", "In Progress", or "Planned".
  4. Update technologies: List the technologies and tools you used.
  5. Update description: Write a brief description of what your project does.
  6. Update key features: List the main features of your project.
  7. Update skills demonstrated: Highlight the programming skills showcased in this project.
  8. Add links: Include links to GitHub repositories, live demos, or documentation.
